**VR 패턴 스튜디오**

다각형과 원호·프레임·원통·계단·기호를 랜덤 생성하고, 실제 외곽선 간 간격을 지켜 배치하는 웹 프로그램입니다. 직접 지정한 색상과 Adobe ASE 팔레트를 사용할 수 있으며, 실제 ArUco 마커를 함께 배치하고 모든 파일을 SVG로 출력합니다.

**웹에서 사용하기:** [VR 패턴 스튜디오](https://hckyeong.github.io/vr-pattern-studio/). 별도 설치 없이 브라우저에서 패턴을 생성하고 SVG로 저장할 수 있습니다. 불러온 SVG·ASE 파일과 패턴 계산은 사용자의 브라우저에서 처리합니다. 저장된 시안은 브라우저·사이트 주소별로 구분되므로, 기존 로컬 주소의 시안이 배포 사이트로 자동 이전되지는 않습니다.

`main` 브랜치에 변경 사항을 푸시하면 테스트와 빌드를 통과한 버전을 GitHub Pages에 자동 배포합니다. 최초 설정과 파일 포함 범위는 [배포 안내](docs/배포_안내.md)를 참고하세요.

**실행하려면** 프로젝트 폴더의 `실행.cmd`를 더블클릭하세요. 빌드 후 `http://127.0.0.1:4173`이 열립니다. 실행 창을 닫으면 서버도 종료됩니다. 이미 실행 중이라면 브라우저에서 같은 주소를 여세요.

로컬에서 실행하려면 Node.js 24를 준비하고 프로젝트 폴더에서 다음 명령을 실행하세요.

```powershell
npm ci
npm run build
npm run preview -- --open
```

개발 화면은 `npm run dev`, 자동 검증은 `npm test`로 실행합니다. 서버는 이 컴퓨터의 `127.0.0.1`에서만 열립니다. 설치가 끝난 뒤 패턴 생성에는 인터넷 연결이 필요하지 않습니다.

**기본 사용 순서입니다.**

1. 캔버스의 가로·세로와 단위를 입력하거나 화면 비율을 선택합니다.
2. 여백, 도형 크기, 간격, 도형별 비중과 색상을 조절합니다.
3. 필요한 경우 추적 마커와 시트 분할 설정을 펼쳐 값을 입력합니다.
4. `패턴 생성`으로 현재 시드를 재현하거나 `새 시안`으로 새 패턴을 만듭니다. 네 가지 시안을 연속으로 만들 수도 있습니다.
5. 시안을 선택하고 `벡터 저장`을 누릅니다. 시트 분할을 켜서 생성한 경우 선택 시트와 배치도를 각각 SVG로 저장할 수 있습니다.

캔버스는 드래그로 이동하고 휠과 확대 버튼으로 확대합니다. 시트 경계 표시를 켜면 전체 원고가 어느 위치에서 분할되는지 볼 수 있습니다. 크기·형태 설정은 다음 생성에 반영되며 색상 변경은 선택 시안에 즉시 반영됩니다. 저장은 현재 선택된 시안의 설정을 따릅니다.

**색상 · 팔레트**에서 배경과 도형의 색 선택기 또는 HEX 입력을 사용하세요. 색상 추가·삭제와 상대 비중 조절을 지원하며, 비중이 0인 색은 도형에서 제외됩니다. 색만 바꾸면 도형의 위치·모양·간격과 다른 보관 시안은 그대로입니다. `흑백 복원`으로 기존 회색 비중에 맞춘 검정·회색과 흰 배경으로 돌아갑니다. 마커는 검정·흰색을, 삽입 SVG는 원본 색을 유지합니다.

`ASE 팔레트 가져오기`에서 Adobe Color 또는 Illustrator로 준비한 `.ase` 파일을 선택하면 색상 목록을 교체합니다. 배경색은 유지되며, 각 색의 `배경색으로 사용` 버튼으로 지정할 수 있습니다. 파일은 로컬에서 처리하고 최대 1MB·32색을 허용합니다. RGB·회색·CMYK·Lab 색상을 읽어 RGB로 출력합니다. CMYK는 인쇄 프로파일 없는 근사 변환이고 Lab의 색역 밖 값은 제한됩니다. 별색 지정은 유지하지 않으며 해당 파일을 읽으면 안내합니다. Adobe의 ASE 공유 안내는 [공식 문서](https://helpx.adobe.com/ph_en/illustrator/desktop/manage-colors/use-swatches/share-swatches-between-applications.html)를 참고하세요.

**계단 도형**은 `도형 믹스 → 계단`의 비중으로 조절합니다. 2~5단의 채움형 계단과 굵은 계단 선을 만들며, 단별 폭·높이·굵기·좌우 방향·회전이 시드에 따라 달라집니다. 비중이 0이면 계단을 생성하지 않습니다. 새 작업의 기본 비중은 15이며, 계단 설정이 없는 이전 시안은 0으로 불러와 기존 설정을 보존합니다. 비중을 올린 뒤 `패턴 생성`을 누르면 반영됩니다.

**로고나 그림을 넣으려면** 왼쪽 `SVG 삽입 → SVG 불러오기`에서 파일을 선택하세요. 한 시안에 SVG 한 개를 넣을 수 있으며, 그림과 마커·패턴 사이에 설정한 도형 간격을 확보합니다. 새 파일의 기본 방식은 `SVG 최외곽선 가까이 배치`입니다. 도형을 자르거나 변형하지 않고 가장 바깥 윤곽 근처로 평행 이동해 배치합니다. 외부로 열린 오목한 공간과 떨어진 조각 사이는 활용하고, SVG 안쪽의 닫힌 구멍에는 패턴을 넣지 않습니다. 화면의 녹색 점선도 사각 상자 대신 실제 보호 윤곽을 표시하며 출력에는 포함되지 않습니다.

이전 시안의 회피 방식은 유지됩니다. `패턴이 피할 영역`에서 새 방식을 선택하면 같은 그림으로 재배치할 수 있습니다. `채워진 도형만 피하기`는 내부 구멍에도 간격을 지켜 배치하며, `SVG 전체 사각 영역`은 그림을 감싸는 사각형 전체를 비웁니다. SVG에 포함된 흰색 도형도 보호하므로, 파일 자체에 배경 사각형이 있으면 이를 제거한 SVG를 사용하세요.

그림을 드래그하면 위치를, 오른쪽 아래 손잡이를 드래그하면 크기를 바꿀 수 있습니다. 방향키는 중심을 1%, Shift와 함께 누르면 5% 이동합니다. 왼쪽의 중심 위치와 가로 크기 숫자도 사용할 수 있습니다. 기본 설정에서는 조작을 마치면 그림을 고정하고 나머지 패턴과 마커 전체를 다시 배치합니다. `이동 후 자동 재배치`를 끄면 여러 번 조절한 뒤 `패턴 생성`을 누르세요. 재배치가 끝나야 변경된 그림을 포함해 저장할 수 있습니다. 기존 시안을 선택하면 그 시안의 그림과 배치도 함께 복원됩니다.

가져오기는 단색 채움·선, 경로·사각형·원·타원·다각형, 그룹 변환, 단순 클래스 스타일과 내부 도형 참조를 지원합니다. 곡선과 선은 정밀한 벡터 면으로 변환하며 SVG의 바깥 빈 여백은 제거합니다. 문자·그라데이션·클리핑·마스크·필터·점선·반투명 효과는 일반 불투명 윤곽선으로 변환한 후 불러오세요. 스크립트·외부 참조·비트맵은 실행하거나 포함하지 않습니다. 파일당 2MB, 요소 3,000개, 채움 도형 500개, 좌표 40,000개가 상한입니다. 출력은 삽입 그림까지 포함한 순수 벡터 SVG입니다.

**크기 입력의 의미를 구분해 주세요.** mm·cm·m는 실측 크기입니다. 픽셀과 비율 모드는 작업 좌표이며, 실제 인쇄 가로 길이를 지정하면 mm로 저장합니다. 비율 모드의 작업 가로는 10,000 단위입니다. 최소 크기·간격·마커 크기·시트 폭은 화면에 표시한 같은 작업 단위로 입력합니다.

여백 58%가 기본값입니다. 여백은 도형의 기하 면적을 제외한 비율이며 색 변경으로 달라지지 않습니다. 배경과 같은 색의 도형도 배치 면적에는 포함됩니다. 간격과 도형 크기를 지키면서 목표 밀도를 채우지 못하면 실제 비율과 안내가 표시됩니다. 각 생성은 최대 180,000회 후보 시도와 10,000개 도형으로 제한됩니다. 시드를 유지하면 같은 생성기 버전에서 좌표를 재현할 수 있습니다.

**시트 출력에서는** 유효 시공 폭과 겹침 폭을 구분합니다. 두 번째 시트부터 왼쪽으로 겹침 폭을 추가하며, 모든 시트의 사방에 재단 여유를 더합니다. 마커 보호 영역은 인접 시트의 겹침·재단 경계도 피합니다. 1:10 출력은 SVG의 물리 크기를 10분의 1로 저장하며, 원래 치수와 축척은 메타데이터에 남깁니다.

원호와 원통은 정밀하게 분할된 벡터 경로입니다. 실제 잉크 영역과 구멍을 계산하며 비트맵이 포함되지 않습니다. SVG에서 도형은 개별 그룹으로 편집할 수 있고, 마커에는 사전명과 ID가 기록됩니다. 인쇄 색상 변환은 인쇄소 사양에 맞춰 적용하세요.

**마커는** ArUcoGen의 `4x4_1000`, `5x5_1000`, `6x6_1000` 사전을 지원합니다. 한 변의 길이는 검정 외곽까지의 길이이며 흰 보호 여백은 별도입니다. 실제 추적 프로그램에도 같은 사전과 출력 후 실측 크기를 설정해야 합니다. 파일의 올바른 검출과 실제 VR 장비의 추적 성능은 별도로 확인해야 합니다.

시안은 화면에 최근 8개까지 표시합니다. 자동 저장은 브라우저의 저장 공간을 사용하며 용량이 큰 결과는 보관 개수가 줄어들 수 있습니다. 중요한 원고는 SVG로 저장하세요. 외부 편집 프로그램에서 다시 저장하면 생성 설정 메타데이터가 제거될 수 있습니다.

구현에는 React·Vite, RBush, Clipper2의 TypeScript 포트를 사용했습니다. 기하 계산은 웹 워커에서 실행하며 취소 시 해당 워커를 종료합니다. SVG 가져오기의 경로 해석에는 [svgpath](https://github.com/fontello/svgpath)를 사용합니다. 일반 패턴 도형의 잠금과 일부 영역만 재생성하는 기능은 아직 지원하지 않습니다.
