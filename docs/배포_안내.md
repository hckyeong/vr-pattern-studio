# 웹사이트 배포 안내

배포 주소: https://hckyeong.github.io/vr-pattern-studio/

이 앱은 별도 백엔드 없이 브라우저에서 동작합니다. GitHub Pages에는 빌드 결과인 HTML·CSS·JavaScript만 배포합니다. 사용자가 불러온 SVG와 ASE 파일, 생성한 시안은 서버로 업로드하지 않습니다. 글꼴을 불러올 때는 Google Fonts에 연결합니다.

## 최초 설정

1. GitHub 저장소의 **Settings → Pages**를 엽니다.
2. **Build and deployment → Source**에서 **GitHub Actions**를 선택합니다.
3. `main` 브랜치에 소스를 푸시하거나 **Actions → 웹사이트 배포 → Run workflow**를 실행합니다.
4. 테스트·빌드·배포 작업이 모두 성공하면 위 주소에서 사용합니다.

워크플로는 Node.js 24에서 `npm ci`, `npm test`, `npm run build`를 실행합니다. 실패한 빌드는 배포하지 않습니다. 배포 권한은 배포 작업의 `pages: write`, `id-token: write`에만 부여하며 별도의 개인 액세스 토큰을 사용하지 않습니다.

## 저장소에 포함하는 파일

- `src/`: 앱, 도형 생성기, SVG 출력, ArUco 사전과 출처 라이선스
- `tests/`: 동작 검증과 검증용 SVG·ASE 파일
- `.github/workflows/deploy.yml`: 테스트와 자동 배포
- `docs/배포_안내.md`, `README.md`: 사용·배포 안내
- `.gitignore`, `index.html`, `package.json`, `package-lock.json`, `tsconfig.json`, `vite.config.ts`, `실행.cmd`: 설치·빌드·로컬 실행 설정

생성 이미지·SVG 결과물(`output/`), 설치 패키지(`node_modules/`), 빌드 결과(`dist/`), 캐시·임시 파일·환경 변수 파일·내부 작업 문서는 소스 저장소에 포함하지 않습니다. `dist/`는 배포 작업에서 다시 생성합니다.

## 업데이트와 로컬 검증

```powershell
npm ci
npm test
npm run build
npm run preview
```

변경 파일을 확인하고 필요한 파일만 커밋하여 `main`에 푸시합니다. 이후 GitHub의 **Actions**에서 배포 결과를 확인합니다. Vite의 상대 경로 설정(`base: './'`)으로 로컬 주소와 저장소 하위 주소에서 같은 빌드 결과를 사용합니다.

자동 저장된 시안은 사이트 주소와 브라우저에 종속됩니다. 로컬 주소에서 저장한 시안이 공개 사이트에 자동으로 나타나지는 않습니다. 필요한 원고는 SVG로 별도 저장하세요.

참고: [Vite 배포 안내](https://vite.dev/guide/static-deploy.html#github-pages), [GitHub Pages 워크플로 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).
